# 《双面绣》第 1–3 集完整剧本

> 竖屏微短剧 · 红果短剧 · 每集预估 1′40″–1′50″
> 符号：`△` 动作 / `OS` 内心独白 / `（画外）` 画外声 / `【闪回】` 闪回 / `【字幕】` 字幕

## 第一集

```
第一集

1-1  青溪县·沈氏绣坊  夜  内
【字幕：前世】
人物：沈禾、阿桃、顾晚、顾言舟、陌生男人（只露手）

△火光从门缝里钻进来，木格窗纸卷边、发黑。满墙绣屏在热浪里轻轻颤动。
△沈禾（素白棉麻衫，乌发低挽一根木簪，左手中指一枚旧银顶针）拽着阿桃冲到后窗。
沈禾：快出去！
阿桃（哭喊）：师父你呢！
沈禾：我拿绣谱。
△沈禾把阿桃推出窗外，转身扑向绣架下的红木匣——匣盖大开，空空如也。
△她冲到门前猛拉门把。门从外面锁死了。
沈禾：开门！
顾晚（门外，轻笑）：姐姐，别喊了。
△门缝里，顾晚（米白套装，珍珠发夹）晃了晃手中一本泛黄的线装册子，封皮四个字：沈氏绣谱。
顾晚：绣谱，我替你收着。
△顾晚身后，顾言舟（金丝眼镜，白衬衫）推了推眼镜，避开沈禾的目光。
顾言舟：禾禾，别怪我。
△地上，沈禾的手机屏幕亮起，热搜弹窗：#县城绣娘沈禾抄袭晚舟实锤#
△浓烟压下来。沈禾跪倒在门边，手指死死抠住门缝。
沈禾OS：顾言舟，顾晚……
△"哗啦"——侧窗玻璃被砸碎。一只男人的手伸进来，手腕系着褪色红绳，红绳上坠一枚小小的绣花平安符。
男人（画外）：沈禾！
△银顶针从沈禾指间滑落，滚进火光里。
△火光吞没画面。
沈禾OS：若有来世，一针一线，我都要讨回来。

1-2  云城·君澜酒店化妆间  日  内
人物：沈禾、化妆师

△"叮"——一声脆响。
△沈禾猛地睁眼，大口喘气。镜子里的她，一身月白缎面礼服，裙摆绣着一株缠枝玉兰。
△她抬起左手——银顶针好好地戴在中指上。
化妆师：沈小姐，做噩梦啦？
△沈禾抓起手机。屏幕：6月18日 上午10:02。锁屏是她和顾言舟的合照。
沈禾OS：订婚宴那天……
沈禾OS：我回来了。
△梳妆台上，红木匣半开，露出一叠绣稿。
沈禾OS：前世就是今天，我亲手把它交了出去。
△沈禾"啪"地合上匣盖。

1-3  同上
人物：沈禾、顾晚、化妆师

△门被推开。顾晚端着一杯茶进来，笑出两个梨涡。
顾晚：姐姐，喝口茶，润润嗓。
△沈禾盯着那杯茶。
【闪回】
△前世。顾晚"脚下一滑"，整杯茶泼在沈禾裙摆上。
△宴会厅里一片哄笑。
宾客甲：县城来的，就是上不了台面。
【闪回结束】
△顾晚走到沈禾身侧，鞋尖往前一绊——
沈禾OS：三，二，一。
△沈禾抱起木匣，起身一让。
△茶杯脱手，整杯茶泼在顾晚自己的白裙上。
顾晚：啊——！
△化妆师憋着笑，低头收拾粉扑。
沈禾（递过一张纸巾）：妹妹，站稳了。
△顾晚攥着纸巾，眼眶说红就红，目光却钉在木匣上。
顾晚：言舟哥让我来取绣稿。
顾晚：上台要交换信物。
沈禾（抱紧木匣）：不劳你。
沈禾：我亲手给他。
△沈禾提起裙摆，走出化妆间。
△顾晚盯着她的背影，脸上的笑一点点褪干净。

1-4  君澜酒店·宴会厅  日  内
人物：沈禾、顾言舟、顾晚、秦岚、顾振华、司仪、宾客、记者

△水晶灯下，背景板一行烫金大字：顾沈两家·订婚之喜。台下宾客满座，时尚媒体的镜头架成一排。
司仪：有请准新娘——
△沈禾抱着木匣走上红毯。
△主桌，秦岚（墨绿丝绒旗袍，翡翠镯）上下打量她，凑向邻座。
秦岚：县城来的，也就这双手值钱。
△秦岚身旁，顾振华（深灰立领外套，手盘一串沉香珠）垂着眼，不动声色。
△台上，顾言舟单膝跪地，一手托着钻戒，一手递来一份文件和钢笔。
顾言舟（温柔）：禾禾，签了它。
顾言舟：以后，我们就是一家人。
△全场掌声。台侧，顾晚已换上一身粉裙，掌声拍得最响。
△沈禾接过文件，没看戒指，直接翻到最后一页。
△特写：第七条——"乙方名下全部绣稿及衍生作品之著作权，无偿归属甲方顾氏服饰所有。"
沈禾OS：前世，我看都没看。
沈禾OS：签掉的，是自己的命。
△顾言舟的笑僵了半秒。
顾言舟（压低声音）：大家都在等。
△沈禾合上文件，接过司仪的话筒，转身面向全场。
沈禾：各位，抱歉。
沈禾：这婚，我不订了。
△话筒一声尖啸。全场死寂。
△顾言舟手里的戒指盒"啪"地合上。

（第一集完）
```

> 编剧备注：救猫咪时刻是 1-1 先推阿桃出窗。先知第一次兑现是 1-3 躲茶反杀。集末留"对真相的欠账"：她为什么退婚，协议里藏着什么。平安符在本集首次埋设。

## 第二集

```
第二集

2-1  君澜酒店·宴会厅  日  内
人物：沈禾、顾言舟、秦岚、顾晚、顾振华、宾客、记者

△闪光灯连成一片。宾客交头接耳。
顾言舟（起身，笑着打圆场）：她紧张，开玩笑呢。
△顾言舟伸手来拿话筒，沈禾往后一让。
沈禾：我没开玩笑。
△沈禾把文件举向台下的镜头。
沈禾：第七条。
沈禾：我所有的绣稿。
沈禾：著作权，无偿归顾家。
沈禾：这是订婚，还是收货？
△台下哗然。镜头齐刷刷对准顾言舟。
秦岚（拍桌而起）：白眼狼！
秦岚：顾家娶你，是抬举你！
△秦岚冲上台，扬手一巴掌扇下来。
△沈禾抬手，稳稳扣住她的手腕。
沈禾：伯母，这双手值钱。
沈禾：您刚说的。
△秦岚脸涨得通红，手腕怎么也抽不回来。

2-2  同上
人物：同上

△顾晚含着泪快步上台，挽住秦岚。
顾晚：姐姐，你误会言舟哥了。
顾晚：条款是保护你的作品。
沈禾：保护？
△沈禾松开秦岚，转向顾晚。
沈禾：上周三，你拿着我三幅绣稿。
沈禾：去做了版权登记。
沈禾：也是保护我？
△顾晚的脸唰地白了。
沈禾：《缠枝玉兰》《寒塘鹭》《春水》。
沈禾：登记人——顾晚。
△台下，一个戴黑框眼镜的女记者飞快划着手机，猛地抬头。
女记者：查到了！作者真是顾晚！
△全场炸开。
△沈禾提起裙摆。灯下，那株缠枝玉兰层层舒展，花瓣丝光从月白渐变到浅粉。
△女记者的手机屏上，登记作品图——一模一样。
沈禾：作品，在我身上。
沈禾：作者，怎么成了你？
△顾晚踉跄后退，撞在顾言舟胸口。顾言舟下意识扶住她的腰，又飞快松开。
沈禾OS：前世在法庭上，我到死都没想通。
沈禾OS：她的登记，为什么比我交稿还早。

2-3  同上
人物：沈禾、顾振华、顾言舟、宾客

△主桌，"嗒"的一声，顾振华把沉香珠搁在桌上，缓缓起身。全场一下安静了。
△他踱上台，声音不高，却压住了满场嘈杂。
顾振华：孩子闹脾气，让各位见笑。
△他转向沈禾，笑容和蔼。
顾振华：沈丫头，下了这个台。
顾振华：这一行，你就没路了。
△沈禾直视着他。
沈禾OS：顾振华……前世，他从没对我说过一句重话。
沈禾：路是自己走的。
沈禾：不是顾家给的。
△沈禾从手包里抽出一张银行卡，放在司仪台上。
沈禾：彩礼，原数奉还。
△她摘下胸前的订婚胸花，丢在红毯上，抱起木匣走下台。
顾言舟（追出两步）：沈禾！
顾言舟：出了这个门，别后悔！
△沈禾没回头。宴会厅大门在她身后沉沉合上。

2-4  君澜酒店门外／出租车内  日  外／内
人物：沈禾、出租车司机、阿桃（电话声）

△大雨倾盆。沈禾把木匣护在怀里冲进雨幕，拦下一辆出租车。
司机：姑娘，去哪？
沈禾：青溪县。
沈禾：沈氏绣坊。
△车窗上雨痕斑驳。沈禾低着头，拇指一遍遍摩挲顶针，肩膀轻轻一抖，不知是哭还是笑。
△手机连震。
△特写：热搜第一——#晚舟主理人顾晚原创遭县城绣娘抄袭#，配图是沈禾裙摆上的玉兰，与顾晚的设计稿并排。
△热搜第四——#订婚宴悔婚女方疑似炒作#
△沈禾嘴角的弧度一点点收住。
沈禾OS：前世，这条热搜三个月后才来。
沈禾OS：这一世，他们更快了。
△手机又响。来电：阿桃。
阿桃（电话里，带着哭腔）：师父！
阿桃：有人在搬咱们绣坊！
△沈禾猛地坐直。

（第二集完）
```

> 编剧备注：先知第二次兑现是 2-2 当场报出登记作品，打脸力度拉满。2-2 顾言舟扶腰又松手，暗埋他和顾晚的私情。2-3 顾振华首次露锋，为第 28 集"先知盲区"埋线。2-4 热搜提前三个月，确立"蝴蝶效应"规则。集末留"对人物的欠账"：绣坊保不保得住。

## 第三集

```
第三集

3-1  青溪县·沈氏绣坊门口  傍晚  外
人物：沈禾、阿桃、刘老板、搬运工若干

△雨后的青石板巷，白墙黛瓦。门头一块褪色木匾：沈氏绣坊。
△几个搬运工正往外抬绣架，绣绷、线轴滚了一地。刘老板（花衬衫，腋下夹皮包）叉着腰指挥。
刘老板：快点搬！今天腾空！
△阿桃（双马尾，碎花围裙）张开胳膊堵在门口。
阿桃：这是外婆的东西！
△一个搬运工扯起一幅《寒塘鹭》绣屏，要往三轮车上扔。
△一只手按住了绣屏。
△沈禾站在台阶下，礼服湿透，怀里还抱着木匣。
沈禾：放下。
刘老板：哟，网红回来了？
刘老板：有人出三倍租金。
刘老板：合同到期，赶紧走人。
沈禾OS：前世，外婆就是被赶出绣坊，一病不起。
沈禾：刘叔，到期了？
△沈禾径直进屋，从外婆床头的铁皮饼干盒里抽出一张泛黄的纸。
沈禾OS：这份合同，前世我收拾外婆遗物时才翻到。
△她回到门口，把纸展开在刘老板眼前。
沈禾：二十年长租。
沈禾：您父亲签的字。
沈禾：还剩三年。
沈禾：违约，赔十倍。
△刘老板凑近一看，脸色骤变，冲搬运工直挥手。
刘老板：撤撤撤！搬回去！
△阿桃一把抱住沈禾，哇地哭出声。

3-2  沈氏绣坊·正屋  夜  内
人物：沈禾、外婆沈秀英、阿桃

△一盏昏黄台灯。外婆沈秀英（满头银发，藏青斜襟布衫，老花镜挂在胸前）坐在绣架前，手里的针一下没停。
△沈禾站在门边，看着外婆的背影，眼眶一点点红了。
沈禾OS：外婆……还在。
△沈禾走过去蹲下，把脸埋在外婆膝头。
外婆（摸着她湿漉漉的头发）：婚退了？
沈禾：退了。
外婆：退得好。
△阿桃举着手机凑过来，屏幕上评论滚动：抄袭狗、蹭热度、滚出苏绣圈。
阿桃：师父，网上全在骂你。
阿桃：供线的老板也都不接单了。
△外婆放下针，拎起沈禾的裙摆，对着台灯缓缓侧过一个角度。
△特写：侧光一斜，玉兰花瓣的丝线纹理里，隐隐浮出一个极小的字——"沈"。
△沈禾屏住呼吸。
外婆：沈家的绣，针里藏名。
外婆：谁偷了去，都抹不掉。
沈禾OS：前世外婆走得急，这句话没来得及告诉我。
△沈禾握住外婆的手。
沈禾：外婆，这件事。
沈禾：先别让任何人知道。
△外婆看了她一眼，点点头，把线头在唇边一抿，重新穿针。

3-3  同上
人物：沈禾、阿桃、外婆

△沈禾换回素白棉麻衫，拔下礼服发饰，重新挽起头发，插上那根木簪。
沈禾：阿桃，架手机。
阿桃：干嘛？
沈禾：直播。
沈禾：他们说我抄。
沈禾：我就当着全网绣。
沈禾：每一针，都让人看着。
△阿桃愣了一秒，用力点头，抹干眼泪去找支架。
△沈禾拉开线柜——空了大半，只剩几绞零散的旧线。
△她拿起手机，一个个拨号。
供线老板（电话里）：沈小姐，对不住。
供线老板：顾家打过招呼了。
△嘟——嘟——
△第三个，第四个……全是忙音。
△屋里只剩外婆穿针引线的"嗤嗤"声。

3-4  沈氏绣坊门口  深夜  外
人物：沈禾、陆川、阿桃

△一束车灯打进巷子。一辆旧蓝色厢式货车停在门口，车门喷着四个字：川行供应链。
△驾驶座跳下一个男人：寸头，黑色工装夹克，肩背笔直。陆川。
△他从车厢里扛下两只纸箱，放在台阶上。
陆川：沈禾？
沈禾：我没订货。
阿桃（从门后探头）：我！我在网上订的！
陆川：下单七家，退了六家。
陆川：我公司小，不挑客。
△沈禾打开纸箱——满满一箱真丝绣线，从藕荷到黛青，一绞绞按色阶排得整整齐齐。
△陆川递来签收单和笔。沈禾伸手去接。
△他抬手的一瞬，袖口滑落——手腕上，一根褪色的红绳，坠着一枚旧旧的绣花平安符。
△沈禾的手僵在半空。
【闪回】
△火光。碎裂的窗。一只伸进来的手——同样的红绳，同样的平安符。
【闪回结束】
陆川：签字。
△沈禾死死盯着他的手腕。笔尖在纸上洇出一个墨点。
沈禾OS：是他……
沈禾OS：前世冲进火里的人。

（第三集完）
```

> 编剧备注：3-1 用前世遗物知识第三次兑现先知。3-2 是全剧最关键的伏笔"针里藏名"，沈禾主动按住不用，留到第 54 集回收。3-3 换回素衣木簪，是人物的视觉蜕变点，也立住"直播自证"这条主线打法。3-4 男二登场是"生意"而不是"救场"，守住辅线的分寸。集末留"对关系的欠账"：他是谁，前世为什么冲进火里。

## 合规自查（剧本层）

| 检查项 | 结果 |
|---|---|
| 政治、宗教、历史敏感 | 无。人物、品牌、城市（云城、青溪县）、酒店、公司均为虚构；时装周不指名具体机构 |
| 暴力与血腥 | 火灾只写火光、浓烟、跪倒，不写伤情和死状；掌掴在落下前被拦住；后续纵火集只拍包扎，不拍伤口 |
| 色情与擦边 | 无。顾言舟和顾晚的私情只用"扶腰又松手"这类动作暗示 |
| 真人与 IP | 不指向任何真实明星、品牌或现有影视角色；苏绣、双面绣属于公共非遗技艺 |
| 公权力形象 | 法院、警方都是正面、依法的形象；反派的收买只针对民间个人和商业机构 |
