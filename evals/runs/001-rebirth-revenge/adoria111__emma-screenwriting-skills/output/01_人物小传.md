# 《双面绣》主要人物小传

> 红果短剧 · 竖屏真人 · 60集 × 1–2分钟 · 都市女频 / 重生 / 复仇 / 事业逆袭 · 受众 25–45 岁女性
> 主线：沈禾的事业逆袭 + 揭开顾家抄袭链。辅线：陆川（克制，不盖过主线）。

## 二、前世时间线（仅沈禾知道，全剧不向任何角色透露"重生"）

1. 9月8日订婚宴：沈禾把《十二花神》原稿当嫁妆交给顾家。
2. 婚后：外婆病重，沈禾困在顾家没能常回县城，外婆一年后离世，至死没见过顾言舟的母亲。
3. 次年春：《十二花神》以顾晚之名作为"晚绣"爆款上市；沈禾抗议，顾家拿出伪造的"三年前原稿"，反告她抄袭。沈禾身败名裂，回到沈家绣坊独居。
4. 两年后：沈禾在外婆的樟木箱里翻出一张旧照片，打电话告诉顾言舟"你妈妈年轻时好像认识我外婆"。第二天夜里，绣坊起火，门被从外面锁死，她只看见锁门的手腕上一抹翡翠绿。

> 今生，顾晚在订婚宴前就偷扫了四幅花神，"抄袭"污名比前世来得更早——前世记忆是会过期的武器。第37集以后，时间线彻底偏离，沈禾不再有先知优势。

## 三、核心人物

### 沈禾 · 女主

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 26岁。清溪县沈家绣坊第四代传人，八岁父母车祸离世，由外婆沈秀英带大。工艺美院刺绣专业毕业，擅长劈丝（一根蚕丝劈成六十四分之一）与双面三异绣（正反两面图案、颜色、针法都不同）。 |
| 外在目标 | 阶段一：三十天凑齐五十万，保住绣坊；阶段二：洗清"抄袭"污名；阶段三：在国际时装周东方专场，以一幅双面绣赢回名誉，并为外婆拿回《双鲤图》。 |
| 底层动机 | 前世她的作品署着别人的名字，她自己死时背着"抄袭犯"的名声——她要的不只是报复，是**署名**：自己的名字、外婆的名字、所有被冒名的绣娘的名字。 |
| 阻碍 | 外部：顾家的资本、担保债务、诉讼与舆论机器；"抄袭"污名；先知记忆逐渐失效。内部：前世太信人，今生矫枉过正——什么都想一个人扛，习惯"将计就计"，留下内鬼阿芳差点害死外婆。 |
| 人物弧光 | 温顺交付（前世）→ 冷静、算计、独自复仇（前期）→ 为将计就计付出代价（第38–40集）→ 学会开口求助但不交出选择权（第44集"不是求，是合作"）→ 从"让顾家付出代价"走到"让每个绣娘署名"（第56、60集）。 |
| 关系 | 外婆：唯一软肋。顾言舟：前未婚夫，她不给他任何回头路。顾晚：镜像对手——一个有手艺没名字，一个有名字没手艺。陆川：从买卖到同盟，感情始终在主线后面一步。 |
| 视觉锚点 | 木质绣针簪（外婆所赠，全剧不换）；中指一枚旧银顶针；压力下按住左手腕（前世烧伤处）的小动作。 |
| 服装弧光 | 第1–3集顾家挑的粉色亮片礼服（格格不入）→ 绣坊时期素色棉麻盘扣衫、藏青袖套 → 火后穿一件被熏黑袖口的旧衫重新起针 → 时装周穿自绣墨青色新中式长裙，裙摆一株禾苗。 |
| 台词气质 | 短、准、不解释。对敌人用事实，对绣娘用名字。代表句："这婚，我不订了。""双面绣，翻过来看。""这一世，我的每一针，都署我自己的名字。" |

### 顾言舟 · 前未婚夫（反派之一）

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 29岁。顾氏服饰副总裁，周曼琳独子，海归，主导"新中式系列"。 |
| 目标 | 完成顾氏上市对赌，从母亲手里拿到实权。 |
| 底层动机 | 一辈子活在周曼琳的影子里，"新中式系列"是他证明自己的唯一项目；他把沈禾的才华当成可打包的资产。 |
| 行动方式 | 体面的PUA："我是为你好""一家人分什么你的我的"；用钱绑人——外婆的八万手术费、绣坊贷款担保都是他经手。与顾晚的私情，是他需要被仰望的出口。 |
| 不知道的事 | 他不知道母亲会纵火。前世他把沈禾那通电话转述给了母亲，无意中成了那场火的引线——他到最后也不知道这件事。 |
| 弧光 | 掌控者 → 失控后先"开价求和"（第13、26、51集）→ 发现母亲把骗补罪责铺在自己签名上（第48集）→ 为自保交出真账（第58集）→ 一无所有。他的后悔是"失去了一支不要名字的笔"，沈禾从不接受。 |
| 视觉锚点 | 金丝边眼镜、深灰西装；说违心话时转袖扣。 |

### 顾晚 · 顾家养女（反派之一）

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 25岁。九岁被周曼琳从邻市福利院领养（当年的公益宣传新闻），原名林晚。对外是"晚绣"创始人、新锐设计师、"非遗守护者"。 |
| 秘密 | 她不会刺绣，连针都穿不好。她的成名作《晚棠》出自陆婶之手，"晚绣"的爆款来自帮扶计划收割的绣娘画稿。 |
| 目标 | 嫁给顾言舟，坐稳顾家儿媳的位置，真正拥有"晚绣"。 |
| 底层动机 | 怕被"退回去"。周曼琳从小告诉她："顾家不养没用的人。"她的价值全靠一个能署名的身份——沈禾的手艺，就是对她空壳的拆穿。 |
| 行动方式 | 白莲示弱、买水军、恶意抬价、收买内鬼、电话恐吓陆婶；第36集接下周曼琳"那间绣坊留着就是祸害"的暗示，雇钱二纵火，自己坐在车里递钱。她偷偷录下了周曼琳的话——她谁都不信。 |
| 弧光 | 嫉妒 → 黑化 → 在时装周被周曼琳当众丢弃 → 反咬交出录音 → 伏法。最后一问："你生来就有外婆、有手艺，我只有顾家，我能怎么办？"——可信的矛盾体，但不洗白。 |
| 视觉锚点 | 珍珠耳钉（第2集丢一只）；米白、浅粉的温柔系套装；展示绣品时永远戴白手套（遮掩她从不拿针）；第32集起戴上周曼琳的翡翠镯。 |

### 周曼琳 · 顾氏董事长（终极反派）

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 52岁。顾氏服饰董事长，顾氏融资担保公司法定代表人。1999年还是个绣品贩子。 |
| 原罪 | 1999年骗走沈秀英的双面绣《双鲤图》，在广交会上包装成"顾家祖传"，拿下第一笔外贸大单，起家至今。《双鲤图》挂在顾氏大厅二十多年。 |
| 目标 | 顾氏上市，守住"百年顾氏"的神话。 |
| 底层动机 | 出身贫寒，极度害怕回到一无所有。她信奉："手艺人卖力气，名字归资本。" |
| 行动方式 | 从不亲手做脏事，只说能抵赖的话。工具：担保债务、两百万诉讼、赞助商施压、"非遗帮扶计划"（领政府补贴、三块钱一件收割绣娘画稿）、暗示纵火。危机时第一反应是找替罪羊——先是钱老板，再是顾晚，连亲儿子都提前铺好了签名。 |
| 弧光 | 静态大反派，不悔改，最终因教唆纵火、骗取补贴被捕。 |
| 视觉锚点 | 墨绿旗袍；思考时转动腕上的翡翠镯——第32集把镯子戴到顾晚手上，此后手腕空着（第40集误认、第47集识破的关键）。 |

### 陆川 · 男二（感情辅线）

| 项目 | 内容 |
|---|---|
| 年龄 / 身份 | 30岁。退伍军人，回乡创办"川行供应链"，做蚕丝、面料和物流，小本生意，自己开货车。 |
| 目标 | 让公司活下去，给母亲治眼睛。 |
| 底层动机 | 父亲早逝，母亲靠绣活供他读书、当兵。他欠母亲，后来才知道母亲的眼睛是替顾晚做枪手熬坏的。 |
| 与沈禾 | 交易（第7集"货是货，人情是人情"）→ 信任（第25集她的预言应验）→ 同盟（第18–19集母亲是受害者）→ 最难时的援手（第39集撞开火门、第44集仓库当绣房、三天调来生丝）→ 合作伙伴 → 结尾一只绣着"川"字、角落藏着"禾"的线包。 |
| 写作红线 | 他从不替沈禾做决定、不替她赢：她自己钉回招牌，他扶梯子；她背出外婆，他撞开门。感情点到为止，全剧不安排吻戏抢主线。 |
| 弧光 | 规矩先于人情 → 为人情放弃大单 → 学会只在她开口时出手。 |
| 视觉锚点 | 寸头、旧军表、卷到小臂的袖口、白色厢式货车车身印"川行"；第39集后右肩烧伤纱布。 |
| 台词气质 | 话少，像签合同："不是求，是合作。" |

## 五、原梗概锁定项与新增设定

**原梗概锁定（未改动）**：沈禾26岁、县城苏绣传人；前世嫁入做服装的顾家，绣稿被顾言舟与顾家养女顾晚偷走做成爆款，她反被扣上抄袭罪名、身败名裂，死于绣坊大火；重生回订婚宴当天，当众退婚、带绣稿回县城老绣坊；直播卖绣品起步，逐步揭开顾家抄袭链；终局在国际时装周以一幅双面绣赢回名誉；陆川退伍后做供应链创业，在她最难时帮过她，感情为辅线。

**本方案新增设定**：周曼琳与《双鲤图》旧案；绣坊抵押贷款由顾氏担保（三十天五十万）；顾晚提前扫描四幅花神；顾晚不会刺绣、"非遗帮扶计划"收割绣娘画稿；陆婶是枪手；"针针有主"暗记规矩；翡翠镯线索；今生纵火；盲评通道；假稿错针陷阱；《薪火》背面九十九个绣娘的名字；"绣娘署名馆"结局。以上均可按出品方意见调整。
