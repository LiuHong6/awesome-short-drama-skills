# 《双面绣》主要人物小传

> 红果短剧 · 竖屏 · 60 集 × 1–2 分钟 · 都市女频 / 重生 / 复仇 / 事业逆袭

## 〇、全剧定位

- **一句话故事**：被未婚夫一家偷稿、污名、烧死在绣坊里的苏绣传人重生回订婚宴当天。她当众退婚，从县城直播起步，一环一环揭开顾家两代人的抄袭链，最后在国际时装周上，用一幅双面绣和绣在上面的名字赢回名誉。
- **主控思想**：手艺人的名誉夺得回来，是因为她最后敢当着所有人，把自己的名字连同别人的名字一起绣上去。光有证据和先知不够。
- **人物轴（手与名）**：沈禾一开始**有手无名**，信奉"绣娘不留名"。周曼琳**有名无手**，一辈子没拿过针，靠买别人的手撑起品牌。全剧要沈禾学会署名，同时不变成周曼琳：她不光署自己的名，也把别人的名字绣上去。
- **总悬念**：顾家为什么非要沈家的稿？答案在二十多年前。周曼琳起家的那件 1998 牡丹旗袍，就是从沈禾外婆手里偷来的。
- **重生的写法（合规提示）**：重生只当作主角的个人经历和信息优势来用。不解释成因，不渲染轮回、因果报应这类玄学。复仇全部走公开对质、证据和法律，不用私刑。先知优势到中点（第 30 集）失效，后半段全靠手艺取胜。

### 人物关系一览

```
                周曼琳（顾母·锦程集团创始人）
```

## 一、沈禾 —— 主角

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 26 岁，青溪县人，沈记绣坊第三代传人，苏绣劈丝能劈到 1/32 |
| 单字性情 | **韧**。出场看着安静，心里其实硬 |
| 外在目标 | 前段：30 天内抢在顾家之前首发《十二花神》，一个月内还清绣坊 23 万旧债。中段：揭穿顾晚和顾家的抄袭链。后段：在国际时装周赢回名誉 |
| 内在需要 | 学会**署名**，学会**把手交给别人**（合作社） |
| 错误信念 | "好东西不必署名，交给对的人就安全。"前世她就是这样把绣稿和一辈子都交给了顾言舟 |
| 镣铐 | ① **恐火**：听到打火机"咔嗒"一声，手就抖；② 债务，县城没渠道；③ 先知优势**会失效**，她却依赖它（第 31 集冤枉刘婶）；④ 第 40 集右手烧伤，后段只能左手绣 |
| 最强的对手是自己 | 傲慢：以为全都"知道"。诱惑：用顾家的手段报复（第 42 集拒绝伪造证据）。规矩：外婆教的"不留名" |
| 标志物 | 外婆传下的樟木绣稿匣；左手无名指上一道顶针磨出的茧 |
| 口头禅 | "绣不出来的，就不是你的。" |
| 前世 | 嫁进顾家三年，绣稿被做成"言舟·SHU"爆款，她反被告抄袭，败诉。外婆在她嫁过去第二年病逝，她没赶上见最后一面。腊月初八，她死在顾家收购来的沈记绣坊的大火里。死前只有一个陌生的供应商给她发过一句"我信你"，她没回 |
| 弧光 | 复仇者 → 带头人 → 署名的手艺人。第 1 集"那我就卖给全中国"，第 58 集当众绣下"沈禾"两个字 |
| 种子台词 | 第 1 集："今天不闹，以后就没机会闹了。" |

**怎样做（区别于一般复仇女主）**：她打脸从来不靠吵，靠**当场动手**：问一个针法、绣一片花瓣、把东西放到灯前。观众的爽点来自手艺本身。

## 二、顾言舟 —— 第一对手（执行者）

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 29 岁，锦程集团长子，新中式子品牌"言舟·SHU"总经理 |
| 单字性情 | **狡** |
| 外在目标 | 靠《花神》系列做出业绩，从母亲手里接过锦程 |
| 自卑与补偿 | 父亲早年出走，母亲把"天才"的名分给了养女顾晚，对他只有一句"你会算账就行"。他最怕自己平庸，就拼命证明自己最会"做局" |
| 对手的刀 | 钱、渠道、律师、舆论团队；学得快，第 33 集开始反过来模仿沈禾的"先知"打法；最后一把刀是纵火 |
| 标志物 | 一只银色打火机，父亲留下的。他戒烟三年了，还天天带着，拇指拨盖子"咔嗒"一声，是他的思考习惯，也是沈禾的噩梦 |
| 口头禅 | "禾禾，今天别闹。" |
| 真相 | 当年接近沈禾是母亲安排的。顾家要的从来不是她这个人，是沈家的针法和外婆那箱旧稿（第 35 集揭） |
| 结局 | 纵火罪被捕（第 57 集）。报应和罪过相当：前世他用火杀人，今生被火灾现场的一缕丝线定罪 |

## 三、顾晚 —— 第二对手（门面）→ 转变者

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 25 岁，顾家养女，"言舟·SHU 主理设计师"，网红 |
| 单字性情 | **媚**，底下是**怯** |
| 具体类别 | 改稿人。真会画，但一针绣不出来，也画不出原创 |
| 错误信念 | "没用的人会被丢掉。"这是七岁被收养那天周曼琳说的原话 |
| 对手的刀 | 舆论（含泪视频、水军）、找替身绣娘、伪证 |
| 标志物 | 一只旧香囊，从小戴着，不知道哪来的。针脚里藏着生母的暗记"珍" |
| 身世 | 生母林秀珍是外婆的徒弟。1998 年她偷了外婆的牡丹稿卖给周曼琳，事后回来认错，正赶上绣坊起火，冲进去抢稿被烧伤，不久去世。周曼琳收养顾晚，一半是封口，一半是把人捏在手里 |
| 转变阶梯 | 第 10–11 集替身翻车 → 第 27–28 集被当场取消资格，雨夜被逐 → 第 37 集听到身世，不信 → 第 38 集为回顾家做伪证（背刺）→ 第 44 集拿到生母的"晚"字绣帕 → 第 49 集自己闯档案室，伸手进火里抢出账本 → 第 56 集当众认罪，替母亲正名，也认下母亲的错 |
| 底线 | 她可以被理解，不会被洗白。抄袭和伪证都要她自己承担后果（第 59 集）。她的转变是她自己选的，沈禾只把真相交给她，从不替她做决定 |

## 四、周曼琳 —— 终极对手（幕后）

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 55 岁，锦程集团创始人，苏绣行业协会副会长，新中式设计大赛评审主席 |
| 单字性情 | **傲** |
| 具体类别 | **买家**。她的信条是"我从不偷，我只买" |
| 自卑与补偿 | 苏州丝绸厂女工出身，年轻时被绣娘们笑"没手艺"，这辈子没学会拿针。补偿的办法是把所有拿针的手都买下来，再把名字换成自己的 |
| 对手的刀 | 行业地位（评审、协会）、"锦程 1998 牡丹原稿"、资本、一句话就能让整个行业不收沈禾的货 |
| 标志物 | 1998 年那件牡丹旗袍，她称之为"锦程的传家之作"。她不知道花心里绣着外婆的暗记"秀英" |
| 口头禅 | "走出这扇门，这一行没人会收你的东西。" |
| 结局 | 自己挑起时装周的对质，自己把证据挂到灯前，自己当着直播说出"是我花钱买的"。被协会暂停职务，锦程被判侵权。她败在自己最得意的那件东西上 |

## 五、陆川 —— 男二（感情辅线）

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 30 岁，退伍运输兵，在县里做"川流供应链"，给县丝线厂、乡下蚕丝作坊拉货 |
| 单字性情 | **稳**，话少 |
| 外在目标 | 让老家那几家小蚕丝厂活下去，不被大集团压价收掉 |
| 错误信念 | "事情自己扛，说出来就是欠人情。"所以他会瞒着沈禾抵押退伍安置房（第 38 集） |
| 与主线的关系 | **只供线，不救场**。他提供的是原料和物流，他打的是自己的仗（第 47 集拒绝收购，连夜绕山路运原料）。时装周高潮他坐在台下，不碰任何证据，也不替沈禾出头 |
| 前世 | 就是那个陌生的供应商，在她身败名裂时发来一句"我信你"。今生他不知道这件事 |
| 感情节奏 | 第 2 集撞箱 → 第 3 集一路送回牡丹页 → 第 13 集火光里陪她，第二天默默装好烟感 → 第 22 集互相不愿欠，红了脸 → 第 39 集各交一个秘密，"这次我当面说：我信你" → 第 60 集一条绣着"川"字的围巾。**全剧不安排吻戏**，克制到底 |
| 标志物 | 军绿色帆布手套，搬货从来不摘 |
| 口头禅 | "顺路。" |

## 六、沈秀英 —— 外婆（智者 / 阴霾的过去）

| 项 | 内容 |
|---|---|
| 年龄 / 身份 | 75 岁，沈记绣坊第二代，1990 年代苏州有名的双面绣绣娘，1998 年后回到青溪县 |
| 单字性情 | **倔** |
| 规矩 | "沈家绣娘，不留名。"她说这是祖上规矩，**其实是创伤**：她署过一次名，被人偷走，反被诬抄袭 |
| 秘密 | 牡丹稿被徒弟林秀珍偷卖；那场火；顾晚的身世。她二十多年不提，是为了不让那个孩子知道自己的母亲做过什么 |
| 暗记 | 沈家每件绣品里都藏一个字，正面看不见，逆光才浮出来：外婆是"秀英"，林秀珍是"珍"，沈禾是"禾"。**这是全剧最大的伏笔** |
| 功能 | 教沈禾闭眼劈丝（第 53 集兑现），传授双面三异绣口诀（第 42 集），在火中拼命要抢的不是原稿，是林秀珍给女儿绣的帕子（第 44 集揭） |
| 弧光 | 从"藏"到"认"。第 29 集摔剪刀，反对署名；第 58 集在病床上看直播，第一次点头 |
| 名台词 | "两面都得干净，才叫双面绣。" |

## 八、对立统一与核心道具

- **沈禾 × 顾言舟**：绑在**前世那场火**上。他要的是沈家的针法和旧稿，她要的是旧稿的清白，谁都不可能让步。
- **沈禾 × 顾晚**：互为镜像。两人的母辈一个是被偷的，一个是偷的。只有顾晚"我是工具"的信念死掉，这层关系才解得开。
- **沈禾 × 周曼琳**：手与名。打破这层关系的，是周曼琳那件旗袍里的暗记。
- **道具系统**：打火机（火 / 威胁）· 樟木绣稿匣（原稿 / 传承）· 香囊与绣帕（"珍""晚"，身世）· 暗记（逆光显字，全剧总伏笔）· 银色袖扣上缠的"禾青"劈丝（纵火证据）· 绣绷上方的倒计时牌（第三幕的计量器）。
