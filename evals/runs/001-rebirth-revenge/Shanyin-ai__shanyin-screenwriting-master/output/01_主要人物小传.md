# 《双面绣》主要人物小传

> 红果短剧 · 竖屏 · 60集 × 1–2分钟 · 都市女频 / 重生 / 复仇 / 事业逆袭

---

```
                  顾承海（锦澜创始人）
                 ╱ 父子          ╲ 养父女
          顾言舟 ─── 暗恋/利用 ─── 顾晚
```

**一句话关系：** 二十年前，顾承海拿走了沈禾母亲的绣品起家；前世，顾言舟和顾晚拿走了沈禾的绣稿。同一家人，偷了同一家人两次。

## 二、主要人物

### 沈禾 ｜ 女主 ｜ 26岁

**身份：** 澄水县"沈氏绣坊"第四代传人。绣坊前身是光绪年间的"沈记绣庄"。她跟外婆学针，能把一根丝线劈成六十四股，擅长乱针绣和双面绣。

**视觉标识：**
- 鬓边一支自己绣的发簪
- 右手中指第一节有一层顶针压出来的老茧
- 重生后外套口袋里一直揣着一把黄铜挂锁，就是前世把她锁在火里的那一把

**前史：**
- 不知道父亲是谁，随母姓。母亲沈素在她六岁时病逝，她由外婆带大。
- 母亲的死因外婆从来不提。家里那只樟木箱，外婆不准任何人碰。
- 大学读的服装设计，毕业后在苏州做绣品设计，因此认识了顾言舟。顾言舟懂行，夸她的稿子"该被全世界看见"。

**前世（Ghost）：**
3月18日订婚，当晚她把绣稿本交给顾晚，"锁进车里保险箱"，又签了婚前协议。4月28日，锦澜用她的"云雀"稿发布系列，一炮而红。7月她发出自己的原作，反被锦澜诬告抄袭，时尚博主"针尖"一篇长文让她身败名裂。她离婚回到县城，准备起诉，可原始绣稿还没拿出来，腊月廿三夜里，绣坊起火。门被人从外面锁死。她最后看见的是一双红色高跟鞋走远，顾言舟坐在车里看了一眼，摇上车窗，还有一只虎口带疤的手砸开窗户，离她只差一寸。

**先知的边界（编剧须严格遵守）：**
- 她的前世记忆**只到腊月廿三**为止，之后的事她不知道。
- 她记得的是**事件和细节**，比如顾晚拍了三十七张照片（这是前世锦澜递交法院的证据清单），云雀的发布日期，温以宁剧组停工的那一周，产业园招标，红毯礼服，"针尖"那篇文章的标题。
- 她每改变一件事，后面的时间线就偏一点。第13集开始出现偏差，第30集起先知基本失效。

| 维度 | 内容 |
|------|------|
| **前世的 Lie** | 嫁进顾家、手艺被大品牌用上，才算出头。所以她亲手把绣稿交了出去。 |
| **今生的 Lie** | 这一世谁都不能信。后面的事我都知道，算准了就能赢。 |
| **Want** | 拿回名誉，让顾家付出代价，保住绣坊。 |
| **Need** | 把手艺和名字摆到明处，和别人一起绣。不靠藏，不靠算。 |
| **Flaw** | 控制欲强，什么都不解释，习惯把身边人当棋子（刘姐、陆川），出了事一个人扛。 |
| **矛盾性** | 外表安静克制，手上的活细得惊人；骨子里狠，当众撕破脸眼都不眨。她最恨顾家偷，可自己也开始藏和算，越来越像顾家。 |

**说话方式：** 话少，句子短，常用反问。她从不说"我知道"，只说一个对方无法辩驳的具体细节，比如"三十七张。第十九页糊了，你又补了一张"。生气时声音反而更低。

**弧光：** 从"藏起来算计着赢"，到"摆在明处一起绣"。

### 顾言舟 ｜ 男反派 ｜ 30岁

**身份：** 锦澜服饰总经理，顾承海的独子。锦澜是做中式高定和"手工苏绣"成衣的苏州品牌。

**视觉标识：** 白衬衫或浅色西装，永远干净；说话时习惯把手搭在对方肩上；开一辆黑色轿车，等人时会无意识地刮两下雨刮器。

**前史：** 从小被父亲说"没手艺、没眼光，只会卖"。他确实懂好东西，看得出沈禾的稿子值多少钱，可他学到的唯一办法是"拿过来"。

| 维度 | 内容 |
|------|------|
| **Want** | 带锦澜登上巴黎时装周主秀，让父亲闭嘴。 |
| **Lie** | 好东西谁拿到就是谁的，名字可以买。 |
| **Flaw** | 体面高于一切，什么都能牺牲：未婚妻、妹妹，最后是一条人命。 |
| **矛盾性** | 他对沈禾的欣赏是真的，但欣赏的方式是占有。越温柔的时候越危险。 |

**说话方式：** 温和，爱用"我们"，从不提高声音，越威胁说得越轻。口头禅是"不急"。

**弧光（反弧光）：** 从体面的掠夺者，到亲手策划纵火的人。第59集在廊桥口被警察带走。

---

### 顾晚 ｜ 女二·镜像角色 ｜ 27岁

**身份：** 顾家养女，锦澜设计总监（第12集被降职）。

**视觉标识：** 一双红色高跟鞋，是顾言舟送她的第一份礼物；手机从不离手。

**前史：**
- 在澄水县福利院长大，小名"小晚"。
- 小时候每个周末去上沈桂芬在福利院开的免费绣花课，是班上最会拿针的孩子，学会了外婆独有的收针法"倒回针"。
- 十二岁被顾承海领养。院长对她说："顾先生看中的是你这双手。"
- 她暗恋顾言舟（无血缘），可在顾家她永远只是个"有用的人"。

| 维度 | 内容 |
|------|------|
| **Ghost** | 被选中的理由是"有用"，不是"被爱"。 |
| **Lie** | 我只有一直有用，才配留在这个家。 |
| **Want** | 坐稳设计总监的位子，嫁给顾言舟，被顾家承认。 |
| **Need** | 在自己绣的东西上，写自己的名字。 |
| **Flaw** | 讨好，自我贬低。不敢恨顾家，就把这股劲变成对沈禾的嫉妒。 |
| **矛盾性** | 她有真天赋，却一直在复制别人。她和沈禾是同一个老师教出来的，走了相反的路。 |

**说话方式：** 甜，开口就叫"嫂子"，习惯先道歉再捅刀。

**弧光（镜像弧）：** 从帮凶，到被认出（第27集）、递线（第38集）、示警（第50集）、交出硬盘（第52集），最后有了只挂自己名字的工作室（第60集）。
- **埋线：** 第1集前世火场里那双走远的红高跟鞋，让沈禾和观众都认定纵火的是她。第52集揭开：今生她接到的命令是"把沈禾约到绣坊"，她没约。前世的她约了。

### 陆川 ｜ 男二·感情辅线 ｜ 31岁

**身份：** 退伍消防兵，在澄水县经营一家小仓配公司"川流仓配"，帮县里的电商仓储、发货，公司常年在倒闭边缘。

**视觉标识：** 左手虎口一道旧疤；一辆快报废的厢货，后视镜上挂着一枚旧军功章；常戴一副劳保手套。

**前史：**
- 父亲是澄水国营丝厂的机修工，丝厂倒闭那年下岗。陆川从小在丝厂的仓库里长大，知道哪里还有老线。
- 服役时参加一次民房火灾救援，屋门被反锁，他砸窗进去，没能把人救出来。手上的疤是那次被玻璃划的。他因此退伍。
- **前世：** 他的仓库和绣坊在同一条街。腊月廿三那晚，砸窗伸手的就是他，没救出来。他不记得前世，沈禾记得那只手。

| 维度 | 内容 |
|------|------|
| **Want** | 把公司撑下去，让县里的货运得出去。 |
| **Need** | 允许自己再信一次一个什么都不解释的人。 |
| **Flaw** | 什么都自己扛，不说；自尊硬，不收人情钱。 |
| **矛盾性** | 是全剧最不会说话的人，也是做得最多的人。 |

**说话方式：** 极少开口，开口只说事："几点""多少件""门锁换了没"。全剧没有一句告白。

**感情线原则（防止盖过主线）：**
1. 他每次出场都在解决主线上的一件具体的事，比如丝线、发电机、仓储、海关文件，**不单独为谈恋爱出场**。
2. 感情只靠动作推进，包括创可贴、穿针、补布贴。
3. 关键节点：第5集初见认疤，第6集夜路，第14集发电机，第18集"你猜得太准了"，第24集讲疤，第36集退回支票，第43集决裂，第48集"门锁换了没"，第51集砸窗抓住她的手，第55集穿针，第60集补布贴。

### 顾承海 ｜ 幕后反派 ｜ 58岁

**身份：** 锦澜服饰创始人。九十年代在澄水开小绣品厂，靠把活外发给绣娘起家。

**视觉标识：** 一只不离手的紫砂杯，说话前先吹茶沫；穿中式立领。

**前史：** 1999年，他把外发绣娘沈素绣的《双面猫》挂上"锦澜1999"的铭牌，当作创始作品。沈素来讨说法，他反告她盗用厂里图样。此后二十年，他把这套办法做成了一个系统，也就是锦澜的"素材库"。

| 维度 | 内容 |
|------|------|
| **信条** | 手艺不值钱，牌子才值钱。 |
| **Want** | 锦澜上市，再拿下巴黎。 |
| **说话方式** | 带方言腔，笑呵呵的，句句是威胁。 |

**结局：** 第58集素材库曝光，第59集被立案调查，锦澜全线撤柜。

---

### 沈桂芬 ｜ 外婆·师父 ｜ 74岁

**身份：** 沈记绣庄第三代，当年是县丝厂绣花车间的技术师傅。二十年来每个周末在福利院免费教孩子拿针。

**视觉标识：** 老花镜，对着窗光穿针，穿不进去；右手腕上常年绑着一根红丝线。

**前史与心结：** 女儿沈素的死是她二十年没说出口的事。她把那幅没绣完的双面猫锁进樟木箱，从此不再碰双面绣。她反对直播，觉得"绣品是磨出来的，不是喊出来的"。

**说话方式：** 只说吃饭和干活的事，比如"锅里有粥""针拿稳"，从不讲道理。

**弧光：** 从封箱、闭口，到在病床上用左手写出"素"字（第33集），在猫的背面扎下第一针（第46集），最后用左手一次穿进针眼（第60集）。

---

### 小满 ｜ 学徒·搭档 ｜ 19岁

**身份：** 外婆收的学徒，心思全在手机上，直播卖九块九包邮的机绣钥匙扣，在线三个人。

**视觉标识：** 黄毛，卫衣，手机支架永远夹在绣架上。

**功能：** 节奏角色，也是观众的代言人。她把沈禾带进直播时代，第11集两年前随手拍的视频救了全店。

| 维度 | 内容 |
|------|------|
| **Want** | 做成一个"大主播"。 |
| **Need** | 被沈禾当成自己人，而不是一个帮手。 |
| **说话方式** | 网络语，语速快，叫"禾姐"，紧张了就话多。 |

**微弧光：** 从卖九块九钥匙扣，到第20集被冤枉出走、第21集拿到针谱第一页、第42集被网暴回乡、第47集回来，最后在直播间教全国网友沈家针法（第60集）。
