先想清楚你要它交回什么，再看视频模型和 agent 对不对得上，最后看许可证和维护情况。星数只能说明关注度，不能说明好不好用。

1. 它交回什么？

  • 只到文字：集纲、分集剧本、审稿意见。见编剧类。
  • 到分镜和提示词：交给你一份能贴进视频模型的镜头表。见分镜和视觉类。
  • 到成片：直接调用视频、配音接口，产出剪好的视频。见全流程类，需要你自己的 API key，会产生费用。

做真人短剧和做漫剧的需求也不同：漫剧更看重角色一致性和画风，真人短剧更看重台词和节奏。

2. 你用哪个视频模型？

提示词写法跟模型绑定，给 Seedance 写的提示词换到可灵上未必好用。先确定要用的模型，再从按视频模型里挑。本站只标仓库说明里明确写了的模型。

3. 你用哪个 agent？

标准的 SKILL.md 大多数 agent 都能用。个别项目只为某一个 agent 写，或依赖某个 agent 的特殊功能，项目页的「支持的 agent」写了仓库里明确提到的那些。

4. 用什么语言写的？

收录的项目里，中文写的 {{lang_zh}} 个、英文 {{lang_en}} 个、中英都有 {{lang_multi}} 个。语言不影响能不能用，但会影响产出风格：中文 skill 里常见红果、抖音的爆款套路，英文 skill 多按好莱坞剧作或海外竖屏剧的格式。做出海短剧，优先看英文或双语的。

5. 许可证能不能商用？

  • MIT、Apache-2.0 等宽松许可证，一般可以商用和修改。
  • 带 NC（非商业）的 Creative Commons 许可证不能商用。
  • 没声明许可证的，默认保留所有权利，严格说只能看不能改着用。收录的项目里有 {{no_license}} 个没有声明。商用前最好问作者。

6. 还有没有人维护？

项目页标了最近更新日期，超过 180 天没更新的会加提示。视频模型更新很快，给旧版本模型写的提示词可能已经过时。
