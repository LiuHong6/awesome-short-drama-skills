收录标准

同时满足以下条件：

  1. 服务短剧或漫剧创作：选题、改编、剧本、审稿、分镜、视觉资产、视频提示词、出片，或者直接服务这些环节的配套工具。
  2. 能装进 agent 使用：标准 SKILL.md、Claude Code 插件，或结构清晰的提示词工作流。完整应用只收进「相关开源平台」，门槛是 1000 星。
  3. 有说明：README 写清楚做什么、怎么装。
  4. 还在维护：近 6 个月有更新，或者内容足够稳定、不需要更新。
  5. 不涉及真实个人：不收以真实个人为对象生成内容的项目。

星数不是门槛，冷门但有独到方法的项目同样收。fork 和高度重合的派生版不收，只收原版。

「人工核对」是什么意思

每个项目都由人读过 README 和目录结构，确认简介、分类、适配的 agent 和视频模型是准确的。它不等于实测过效果。实测单独做，结果放在实测页。

怎么更新

  • 每周一自动刷新星数、更新时间、许可证和 skill 列表，网站随之重新生成。
  • 新项目先由脚本按关键词搜出候选，再人工审核后收录。
  • 首页的「本周新增」列出最近 7 天收录的项目。

排序和精选

列表默认精选在前，其余按 GitHub 星数排序。「精选」只按我们对项目质量的判断给出。目前没有付费收录，也没有付费排名。

数据和引用

我们写的简介、点评和分类以 CC0 发布，可以自由使用和引用，不需要署名。项目页里的「仓库自述」和 SKILL.md 说明摘自原仓库，版权归原作者；作者希望撤下，提个 issue 就行。机器可读的版本：

  • /data.json：全部条目和分类的 JSON。
  • /llms.txt：给大模型读的站点摘要。
  • GitHub 仓库：原始数据、生成脚本和修改历史。
