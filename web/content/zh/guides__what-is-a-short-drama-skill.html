一句话：AI 短剧 skill 是一个装进智能体（千问办公、豆包电脑版、龙虾 OpenClaw、Claude Code、Codex 等）的文件夹，核心是一份 SKILL.md，写明做短剧的某个环节该按什么流程、交什么格式、守什么标准。装上以后，你用对话提需求，agent 就按这套方法去写集纲、剧本、分镜或视频提示词。

SKILL.md 里写了什么？

  • 开头的 name 和 description：告诉 agent 这个 skill 叫什么、什么时候该用。agent 平时只读这两行，遇到相关任务才读全文。
  • 正文：分几步做、每一步问你什么、产出什么格式，比如「每集 1 到 2 分钟、第 10 集设付费卡点、结尾必须留钩子」。
  • 可选的附件：模板、参考资料、检查脚本。有的短剧 skill 会用脚本检查分镜时长、角色有没有漏掉参考图。

这种格式叫 Agent Skills，最早由 Anthropic 提出，现在 Claude Code、Codex、Cursor、OpenCode、Gemini CLI、OpenClaw 都能用，国内的千问办公、豆包电脑版、WorkBuddy、Kimi Code、Qwen Code、CodeBuddy、Trae、Qoder 也支持。同一个 skill 一般不用改就能装进不同的 agent。

短剧 skill 能做哪些事？

按短剧的制作流程，本站把 skill 分到九个阶段（一个 skill 可以覆盖多个阶段）：

  • 选题 · IP 评估：判断一个故事值不值得拍、适合什么平台。
  • 改编：把小说、网文改成短剧：删支线、压时间线、把心理描写变成动作和台词。
  • 人物 · 角色资产：人物小传、角色设定图、形象和音色提示词。
  • 结构 · 集纲 · 钩子：定集数、排每集的事件、设计开头钩子和付费卡点。
  • 剧本 · 对白：写分集剧本。
  • 审稿 · 质检 · 去 AI 味：按规则挑毛病，去掉一看就是 AI 写的套话。
  • 分镜 · 镜头设计：把剧本拆成镜头，写清景别、运镜、时长。
  • 视频 / 图像提示词：给 Seedance、可灵、MiniMax 等模型写提示词。
  • 出片 · 配音 · 剪辑：调用视频和配音接口生成素材，再剪成成片。

为什么用 skill，而不是每次贴提示词？

  • 稳定：同一套流程反复跑，第 1 集和第 60 集按同样的标准写。
  • 能检查：skill 可以带脚本，自动检查格式、时长、人设有没有前后矛盾。
  • 能串起来：改编 skill 的产出交给分镜 skill，分镜的产出交给提示词 skill，见推荐组合。
  • 能改：觉得哪条规则不合适，直接改 SKILL.md。

有什么局限？

  • 剧本好不好，最终取决于 agent 背后的模型；skill 管的是方法和格式。
  • 出片要调用视频模型，需要你自己的账号或 API key，会产生费用。
  • 带脚本的 skill 会在你的电脑上执行代码，安装前先读一遍 SKILL.md。
  • 本站的「人工核对」只核对仓库说明和分类，不代表实测过效果；实测结果会陆续放在实测页。

从哪里开始？

  1. 先看推荐组合，找一个和你的目标最接近的。
  2. 按安装指南装上，先跑一集。
  3. 不合适再按怎么选换。
