最快的方法：装好 Node.js 后，在终端运行 npx skills add 作者/仓库名，按提示选择要装进哪个 agent。下面是细节。

一、准备

  • 一个支持 Agent Skills 的 agent：Claude Code、Codex、Cursor、OpenCode、Gemini CLI、OpenClaw 等。
  • Node.js，因为下面的命令要用 npx。

二、一行命令安装

# 装到当前项目（默认）
npx skills add eternityspring/shuohao-skills

# 装到用户目录，所有项目都能用
npx skills add eternityspring/shuohao-skills -g

# 指定装进哪些 agent
npx skills add eternityspring/shuohao-skills -a claude-code -a codex

# 先看仓库里有哪些 skill，再只装其中一个
npx skills add eternityspring/shuohao-skills --list
npx skills add eternityspring/shuohao-skills --skill novel-outline

每个项目页都写好了这个项目的安装命令。命令来自 skills CLI，本站没有逐个验证，个别仓库的安装方式以它自己的 README 为准。

三、装到了哪里？

agent项目安装全局安装（-g）
Claude Code.claude/skills/~/.claude/skills/
Codex.agents/skills/~/.agents/skills/
Cursor.agents/skills/~/.cursor/skills/
OpenCode.agents/skills/~/.config/opencode/skills/
Gemini CLI.agents/skills/~/.gemini/skills/
OpenClawskills/~/.openclaw/skills/

四、手动安装

不想用命令行工具，也可以手动装：把仓库下载下来，找到包含 SKILL.md 的文件夹，整个复制到上表对应的目录里。一个文件夹就是一个 skill。

五、装完怎么用？

  • 新开一个会话，让 agent 重新加载 skill。
  • 直接说需求，比如「把这本小说改成 60 集短剧，先出集纲」。agent 会根据 skill 的描述自动选用。
  • 也可以点名要用哪个 skill。在 Claude Code 里，skill 还可以用 /skill 名字 直接调用。
  • 有的 skill 会先问你几个问题（题材、集数、平台），如实回答就行。

六、提示词文件怎么用？

标着「提示词文件」的项目不是标准 skill，不能用命令安装。按它的 README 把提示词复制进对话或项目里使用。

七、安装前的安全检查

  • 先读一遍 SKILL.md，看它会让 agent 做什么。
  • 有 scripts/ 目录的，看一眼脚本会执行什么命令、会不会联网上传文件。
  • 需要 API key 的（出图、出视频、配音），用你自己的 key，并留意费用。

常见问题

装了没反应？
确认文件夹在上表的目录里、里面直接就有 SKILL.md；新开会话再试；直接点名 skill 的名字。
中文 skill 能在英文环境用吗？
能。模型读得懂中文说明，产出的语言按你的要求来。目前收录的项目里，中文写的 {{lang_zh}} 个、英文 {{lang_en}} 个、中英都有 {{lang_multi}} 个。
能同时装好几个短剧 skill 吗？
能，但全流程类的项目各有一套文件结构，混用前先用一个项目完整跑通一集。
