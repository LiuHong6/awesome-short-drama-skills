Start with what you want it to hand back, then check that the video model and agent match, then look at the license and maintenance. Stars show attention, not quality.

1. What does it hand back?

  • Text only: episode outlines, scripts, review notes. See screenwriting.
  • Storyboards and prompts: a shot list you can paste into a video model. See storyboards and visuals.
  • Finished video: calls video and voice APIs and returns an edited cut. See full pipelines. This needs your own API keys and costs money.

Live-action short dramas and manju also need different things: manju depends on character consistency and art style, live-action on dialogue and pacing.

2. Which video model will you use?

Prompt syntax is tied to the model; a prompt written for Seedance may not work in Kling. Settle on the model first, then pick from by video model. Only models that a repo's README names are listed.

3. Which agent do you use?

Most agents can use a standard SKILL.md. A few projects are written for one agent or depend on one agent's features. "Agents" on each project page lists only the agents the repo names.

4. What language is it written in?

Of the listed projects, {{lang_zh}} are written in Chinese, {{lang_en}} in English and {{lang_multi}} in both. Language does not decide whether a skill works, but it shapes the output: Chinese skills often follow the hit formulas of Hongguo and Douyin, English ones tend to follow Hollywood screenwriting or the format of overseas vertical dramas. For dramas aimed at overseas viewers, start with English or bilingual skills.

5. Does the license allow commercial use?

  • Permissive licenses such as MIT and Apache-2.0 generally allow commercial use and modification.
  • Creative Commons licenses with NC (non-commercial) do not.
  • No license declared means all rights reserved by default: strictly speaking you may read it but not reuse it. {{no_license}} listed projects declare no license. Ask the author before commercial use.

6. Is it still maintained?

Project pages show the last update date and flag projects with no updates in 180 days. Video models change fast, and prompts written for an older model version may be out of date.

After you choose

  • Run one episode through a single project first, then think about mixing. Full pipelines each use their own file layout and rarely line up with each other.
  • If you do not know where to start, use the suggested stacks.
  • We give the same premise to different skills and put the outputs side by side on the tests page.
