In one sentence: an AI short drama skill is a folder you install into an agent (Claude Code, Codex and others). At its core is a SKILL.md file that spells out the steps, output format and standards for one part of making a short drama. Once installed, you describe what you want in plain language and the agent follows that method to write episode outlines, scripts, storyboards or video prompts.

What is inside a SKILL.md?

  • A name and description at the top: they tell the agent what the skill is and when to use it. The agent reads only these two lines until a task calls for the full file.
  • The body: the steps, what to ask you at each step and the output format, for example "1–2 minutes per episode, paywall point at episode 10, every episode ends on a hook".
  • Optional extras: templates, reference material and check scripts. Some short drama skills use scripts to check shot durations or catch characters missing a reference image.

The format is called Agent Skills. Anthropic introduced it, and Claude Code, Codex, Cursor, OpenCode, Gemini CLI, OpenClaw and others now support it. The same skill usually installs into different agents without changes.

What can a short drama skill do?

This site sorts skills into nine production stages (one skill can cover several):

  • Topic selection · IP evaluation: decide whether a story is worth making and which platform suits it.
  • Adaptation: turn a novel or web novel into a short drama by cutting subplots, compressing the timeline and turning inner monologue into action and dialogue.
  • Characters · character assets: character bios, design sheets, appearance and voice prompts.
  • Structure · episode outlines · hooks: set the episode count, plan each episode, design opening hooks and paywall points.
  • Script · dialogue: write the episode scripts.
  • Review · QA · de-AI: check against rules and strip phrasing that reads as AI-written.
  • Storyboard · shot design: break the script into shots with shot size, camera movement and duration.
  • Video / image prompts: write prompts for Seedance, Kling, MiniMax and other models.
  • Video generation · voiceover · editing: call video and voice APIs, then cut the footage into episodes.

Why use a skill instead of pasting a prompt each time?

  • Consistency: the same method runs every time, so episode 1 and episode 60 follow the same standards.
  • Checks: a skill can ship scripts that check format, duration and character continuity.
  • Chaining: an adaptation skill hands off to a storyboard skill, which hands off to a prompt skill. See suggested stacks.
  • Editable: if a rule does not suit you, change the SKILL.md.

What are the limits?

  • Script quality ultimately depends on the model behind the agent; the skill supplies the method and format.
  • Generating video calls a video model, which needs your own account or API key and costs money.
  • Skills that ship scripts run code on your machine. Read the SKILL.md before installing.
  • "Checked" on this site means the README and category were reviewed, not that the skill was tested. Test results will appear on the tests page.
