Awesome Short Drama Skills is an open-source directory of AI short drama and manju skills. The website and the GitHub list are built from the same data. {{maintainer_line}}

Inclusion criteria

A project must meet all of these:

  1. Serves short drama or manju creation: topic selection, adaptation, scripts, review, storyboards, visual assets, video prompts, production, or a companion tool that directly serves these steps.
  2. Works inside an agent: a standard SKILL.md, a Claude Code plugin, or a clearly structured prompt workflow. Full applications go only under "related open-source platforms", with a 1,000-star bar.
  3. Documented: the README says what it does and how to install it.
  4. Maintained: updated in the last six months, or stable enough not to need updates.
  5. No real people: projects that generate content about real individuals are not listed.

Stars are not a bar; lesser-known projects with a distinctive method are welcome. Forks and near-duplicate derivatives are not listed; the original is.

What "checked" means

A person read each project's README and folder structure and confirmed that its description, type, agents and video models are accurate. It does not mean the skill was tested. Tests are done separately and published on the tests page.

How it updates

  • Every Monday, stars, update dates, licenses and skill lists refresh automatically and the site rebuilds.
  • A script searches for candidates by keyword; a person reviews each one before it is listed.
  • "New this week" on the home page shows projects added in the last seven days.

Ordering and featured picks

Lists show featured projects first, then sort by GitHub stars. "Featured" reflects only our judgment of quality. There is currently no paid listing and no paid placement.

Data and citation

The data is released under CC0: use and cite it freely, no attribution required. Machine-readable versions:

  • /data.json: every entry and category as JSON.
  • /llms.txt: a site summary for language models.
  • GitHub repo: raw data, build scripts and change history.

Suggest a project or a correction

Open an issue to suggest a project; self-submissions are welcome. Every project page has a "Report an error" button for corrections.
