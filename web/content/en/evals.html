"Checked" in the directory only means a project's details are accurate, not that it works well. This page holds the tests: the same premise goes to different skills, and the outputs are laid side by side unedited so you can judge for yourself.

Round one is done (2026-10-17): 10 script-writing skills plus a control with no skill, one run each on the same premise. Every output, transcript and blind review is on GitHub (in Chinese).

Round one: script-writing skills

The premise, Double-Sided Embroidery: a female-audience urban rebirth-revenge story in which a Suzhou embroidery heir breaks off her engagement at the banquet. It targets Hongguo, vertical, 60 episodes of 1–2 minutes. Deliverables were a character bible, a 60-episode outline with paywall points, and full scripts for episodes 1–3. Every run used Claude Code with claude-opus-5-5 at high effort and identical prompts. Outputs were anonymized as A–K and reviewed blind, with no overall scores.

Findings

  1. The story skeletons converge, with or without a skill. All 11 outputs have a character named Xiaoman. All put the first paywall point at episode 10, use a name hidden in the stitches and revealed by raking light as evidence, and replay the past-life fire. Ten open on that fire, and five use the identical breakup line "这婚，我不订了。" ("I'm calling off this engagement."). Skills mostly change format, writing habits and pacing discipline; a distinctive premise still has to come from a person.
  2. The control's problems are runtime and an overpowered heroine. Without a skill, each episode ran 1.5–2 times the limit, voice-over was heavy and the heroine's foreknowledge never failed. Most skill outputs read more like short drama on runtime, format and making foreknowledge costly.
  3. General screenwriting skills held their own. screenwriting-skills and Shanyin Screenwriting Master were not built for short drama, yet they were near the top on characters, dialogue and AI tells. The short-drama skills were stronger on paywall points, production feasibility and asset lists.
  4. Everything needs cleanup before it goes to a crew. Several scripts carry metadata headers, IDs and checkpoints, and none gives a per-episode list of locations, cast and props.

Limits of this round

  • No scripts were run. For safety, the agent could only read and write its own folder, with no shell and no network. Several skills ship check scripts that were skipped; the agent checked by hand instead.
  • One run each. Another run would give different output, so these are observations, not verdicts.
  • The fixed reply skips confirmation steps. The standard reply told the agent to decide for itself, so skills that normally pause for approval after the outline did not.
  • The reviewers are AI. Both blind reviewers were AI, and the editor checked quotes and conclusions. Next round we plan to add human screenwriters and allow scripts in a sandbox.

Method

  1. Same input: one premise with genre, episode count and platform, shared by every skill in the round.
  2. Same environment: the same agent, model and reasoning effort, with versions recorded.
  3. Pinned skill versions: the commit of each repo at test time is recorded.
  4. Each skill's own process: the run opens by calling the entry skill. When a skill stops to ask, it gets the same fixed reply and nothing more, and the whole exchange is recorded.
  5. Every output kept: no cherry-picking; every run is published.
  6. Blind review: reviewers do not know which skill produced which output.

What we look at

DimensionWhat we look for
HooksDo the opening and each episode ending make you want to keep watching?
CharactersAre motives clear and behavior consistent?
StructureDo pacing, escalation and twists hold up, and are paywall points well placed?
DialogueDoes it sound like people talking, and do characters sound different?
AI tellsHow many stock phrases, tricolons and empty adjectives?
UsabilityIs the runtime right, and how much editing before it can be shot?

Reviews give observations and examples, not overall scores. The runner is evals/run.py, so anyone can reproduce the method.
