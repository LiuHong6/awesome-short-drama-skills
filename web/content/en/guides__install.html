The quickest way: with Node.js installed, run npx skills add owner/repo in a terminal and pick which agents to install into. QwenWork, Doubao desktop and WorkBuddy don't use the command line; see section 4.

1. What you need

  • An agent that supports Agent Skills: Claude Code, Codex, Cursor, OpenCode, Gemini CLI and OpenClaw, or Chinese agents such as QwenWork, Doubao desktop, WorkBuddy, Kimi Code, Qwen Code, CodeBuddy, Trae, Qoder and Lingma.
  • For the command-line install, Node.js, because the commands below use npx.

2. Install with one command

# install into the current project (default)
npx skills add eternityspring/shuohao-skills

# install into your user directory, available in every project
npx skills add eternityspring/shuohao-skills -g

# choose which agents to install into
npx skills add eternityspring/shuohao-skills -a claude-code -a codex
npx skills add eternityspring/shuohao-skills -a openclaw -a trae

# list the skills in a repo, then install just one
npx skills add eternityspring/shuohao-skills --list
npx skills add eternityspring/shuohao-skills --skill novel-outline

Every project page shows its install command. The commands come from the skills CLI and were not verified one by one; if a repo's README says otherwise, follow the README.

4. Manual install

You can also install by hand: download the repo, find each folder that contains a SKILL.md, and copy the whole folder into the matching directory above. One folder is one skill.

QwenWork, Doubao desktop and WorkBuddy are not in the skills CLI's list. Install like this:

AgentHow to install
QwenWork (Alibaba)Copy the skill folder into ~/.qwenworkcn/skills/
Doubao desktop (ByteDance)On the Skills page, click "+ Add", choose upload and pick the skill folder. The SKILL.md must start with a YAML name and description; menu names vary a little between versions
WorkBuddy (Tencent)Copy the skill folder into ~/.workbuddy/skills/, or into .workbuddy/skills/ inside a project to use it only there

OpenClaw-based products such as QClaw and KimiClaw each have their own skills page; follow the product's instructions.

5. How to use it

  • Start a new session so the agent loads the skill.
  • Describe what you want, for example "Adapt this novel into a 60-episode short drama, start with the episode outline." The agent picks the skill from its description.
  • You can also name the skill you want. In Claude Code you can call a skill directly with /skill-name.
  • Some skills ask a few questions first (genre, episode count, platform). Answer them as you would for a writer.

6. What about prompt files?

Projects marked "prompt files" are not standard skills and cannot be installed with the CLI. Copy the prompts into your chat or project as the README describes.

7. Safety checks before installing

  • Read the SKILL.md to see what it will make the agent do.
  • If there is a scripts/ folder, look at what commands the scripts run and whether they upload anything.
  • For skills that need API keys (image, video, voice), use your own key and keep an eye on cost.

Common questions

I installed it but nothing happens.
Check that the folder is in one of the directories above with SKILL.md directly inside it, start a new session, and try naming the skill.
Can I use a Chinese-language skill in English?
Yes. The model reads the Chinese instructions fine and writes in whatever language you ask for. Of the listed projects, {{lang_zh}} are written in Chinese, {{lang_en}} in English and {{lang_multi}} in both.
Can I install several short drama skills at once?
Yes, but full-pipeline projects each use their own file layout. Run one episode all the way through a single project before mixing.
